# PaperTrade 模拟美股

一个手机优先、无需构建的静态美股模拟交易网页。使用原生 HTML、CSS、JavaScript，可直接通过 GitHub Pages 发布。

## 本地运行

直接打开 `index.html`，或使用任何静态文件服务器托管本目录。

## 功能

- $100,000 虚拟初始资金和本地账户保存
- 热门美股列表、搜索、涨跌筛选和自选
- Twelve Data 个股/指数报价、报价时间和按需历史 K 线
- 市价单与限价单、撤单、虚拟滑点、订单和成交记录
- 持仓成本、可用资金及浮动盈亏
- 手机端底部导航和股票交易面板

行情通过用户自行配置的 Twelve Data API Key 获取，未连接行情时不展示旧的演示股价。API Key 仅存于当前浏览器会话并通过 HTTPS 请求直接发送给 Twelve Data；请核对账户计划、额度与网页展示权限。模拟账户数据保存在当前浏览器的 localStorage，不同设备和浏览器之间不共享。市价单按最新可用报价模拟成交并计入 0.05% 滑点；限价单根据之后获取的报价模拟触发。没有真实订单簿、撮合、交易所路由或券商连接。仅供学习练习，不构成投资建议。

## 发布到 GitHub Pages

仓库根目录部署时，进入 GitHub 仓库的 **Settings → Pages**，选择 **Deploy from a branch**、`main` 分支及 `/(root)` 目录并保存。每次向 `main` 推送更新后，Pages 会自动重新发布。
