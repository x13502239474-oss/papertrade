## 核心特性（美股模拟终端）

### 1. 真实可验证行情与零虚构回退
- **严格零假数据**：移除全部硬编码示例股价、随机涨跌、合成 K 线与虚假成交量。未连接行情、密钥无效、额度耗尽或网络失败时明确显示对应状态。
- **数据源与元数据透明展示**：清晰展示数据源名称、交易所（`NASDAQ` / `NYSE` / `NYSE Arca`）、币种（`USD`）、交易所报价时间、本地同步时间及套餐实时/延迟说明。
- **精确美股交易日历 (`js/marketHours.js`)**：基于 `America/New_York` 时区与 NYSE/NASDAQ 官方规则，精确区分**常规交易时段（09:30–16:00 ET）**、**盘前（04:00–09:30 ET）**、**盘后（16:00–20:00 ET）**、**周末休市**、**美国法定市场假期**（元旦、马丁路德金日、总统日、耶稣受难日 Good Friday、阵亡将士纪念日、六月节、独立日、劳工节、感恩节、圣诞节）以及**提前休市日（13:00 ET 收盘）**，并支持与数据源 `is_market_open` 状态交叉校验。
- **缓存、节流与配额保护 (`js/marketData.js`)**：内置 60 秒单标的节流缓存、5 分钟 K 线独立缓存、10 秒手动刷新冷却，以及滑动 60 秒窗口配额保护（适配免费层 `8 credits/min` 与专业层/代理层）。

### 2. 安全合规的双模式行情接入
GitHub Pages 是公开静态站点，任何写入仓库代码、配置文件或 URL 查询参数的 API Key 均会暴露给所有访客；同时 Twelve Data、Finnhub、Polygon 等提供商的个人免费套餐仅限个人自用（Personal / Internal Use），不允许直接用于公开网站向第三方访客分发行情。因此本终端采用双模式架构：
1. **服务端安全代理模式（推荐公开部署）**：仓库提供可直接部署的 Cloudflare Worker 模板 [`proxy/cloudflare-worker.js`](proxy/cloudflare-worker.js) 及部署文档 [`proxy/README.md`](proxy/README.md)，将密钥存储在服务端加密环境变量 `TWELVE_DATA_API_KEY` 中，限制 `ALLOWED_ORIGIN` 并启用边缘缓存（面向公众展示前请确认持有对应商业展示授权）。
2. **个人会话密钥模式（BYOK，个人本地测试）**：用户在浏览器“行情设置”中输入自己的 Twelve Data API Key，密钥**仅保存在当前标签页 `sessionStorage`**，通过 HTTPS `Authorization: apikey <KEY>` 请求头发送（绝不放入 URL 或代码库）。断开或更换密钥不会影响 `localStorage` 中的模拟账户数据。

### 3. 完整模拟交易与资金核算 (`js/account.js`, `js/orders.js`)
- **委托类型**：支持买入/卖出方向的**市价单（Market）**与**限价单（Limit）**。
- **小数股支持**：支持最小 `0.0001` 股、最多 4 位小数精度校验，并提供 `25% / 50% / 75% / MAX` 快捷仓位计算。
- **模拟费用与滑点披露**：市价单计入双向 `0.05%` 模拟滑点，平台模拟佣金 `$0.00`；所有测算在下单前逐项透明列示。
- **报价新鲜度风控**：报价超过 15 分钟未同步即标记为“已过期”，自动禁用模拟市价单，且绝不使用陈旧报价触发等待中的限价单。
- **完整账户指标**：实时核算总资产、现金总额、可用购买力、限价买单冻结资金、总持仓、限价卖单冻结股数、可卖股数、加权平均成本、未实现浮动盈亏与已实现累计盈亏。
- **订单全生命周期与筛选**：完整记录等待中、已成交、已撤单、已拒绝（含现金不足/持仓不足拒绝原因）订单，支持多维筛选、订单详情弹窗与账户重置二次确认。

### 4. 证券目录与非上市/退市证券合规拦截 (`js/catalog.js`)
- 内置 80+ 只美股普通股（`Stock`）、宽基与行业 `ETF`、美股 `ADR`，支持中英文检索、排序、分页，并在连接数据源后支持全市场远程代码检索与跨交易所去重。
- **非上市公司与退市拦截**：搜索 `Anthropic`（以及 `OpenAI`、`SpaceX`、`Stripe`、`ByteDance` 等非上市公司，或 `TWTR`、`BBBY`、`SIVB` 等已退市代码）时，明确标为 **“非上市公司 / 不可交易”** 或 **“已退市 / 不可交易”** 并附上官方公司信息链接（如 Anthropic 官方信息页），绝不虚构股票代码、股价或开放下单。

## 本地运行与测试

由于采用原生 ES Modules（`<script type="module">`），请在任意本地静态 HTTP 服务器下运行：

```bash
# 启动静态服务器（任选其一）
npx serve .
# 或
python -m http.server 8080

# 运行 Node.js 自动化测试套件
node --test tests/terminal.test.mjs
```
