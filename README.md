# PaperTrade 模拟美股

一个手机优先、无需构建的静态美股模拟交易网页。使用原生 HTML、CSS、JavaScript，可直接通过 GitHub Pages 发布。

## 本地运行

直接打开 `index.html`，或使用任何静态文件服务器托管本目录。

## 功能

- $100,000 虚拟初始资金和本地账户保存
- 热门美股列表、搜索、涨跌筛选和自选
- 股票走势图与详情
- 买入、卖出及持仓盈亏估算
- 手机端底部导航和股票交易面板

本项目是纯前端演示。行情为代码中写入的示例数据，并非实时行情；账户数据只存在当前浏览器的 localStorage，不同设备和浏览器之间不共享。仅供学习练习，不构成投资建议，也不连接真实券商。

## 发布到 GitHub Pages

仓库根目录部署时，进入 GitHub 仓库的 **Settings → Pages**，选择 **Deploy from a branch**、`main` 分支及 `/(root)` 目录并保存。每次向 `main` 推送更新后，Pages 会自动重新发布。
