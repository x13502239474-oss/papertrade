# PaperTrade A 股模拟交易

A mobile-first static practice app for Chinese A-share paper trading. No build step is needed.

## Features

- ¥100,000 virtual starting balance with browser-local persistence
- Shanghai and Shenzhen stock watchlist, search, gainers and decliners
- Stock detail charts and a holdings view
- Simulated buy/sell orders with 100-share buy lots
- T+1 settlement: shares bought today become sellable the next local calendar day

All stock and index values are illustrative demo data, not live quotes. Account state is saved in this browser only. The app is for practice and does not connect to a broker or provide investment advice.
